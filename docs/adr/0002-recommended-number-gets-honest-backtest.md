# เลขแนะนำ is tracked and backtested exactly like a Pick — no exemption

**Status:** accepted

เลขแนะนำ joins the existing Track Record (auto-snapshot, Hit/Miss, Hit-rate trend) and gets its own Edge computed against its own baseline, rather than being presented as a self-evidently trustworthy signal because "multiple formulas agree." We considered shipping it without backtest coverage (faster, and cross-formula agreement feels intuitively meaningful) but rejected that: this project's core rule is that no metric is exempt from honest, baseline-adjusted evaluation (ห้ามเหลี่ยม backtest), and agreement-by-chance rates differ a lot by field type — `bottom2` has 6 producing groups (higher chance of coincidental pairwise agreement among only 100 possible values) versus `front3`/`back3exact`/`prize1_last2` which have exactly one possible producing pair (D vs F/Codex) against 1,000 possible values. Without its own Edge, a เลขแนะนำ hit rate could look impressive purely from `bottom2` coincidences while being meaningless — the same failure mode this project has already guarded against elsewhere (see [[feedback-metric-shopping]] equivalent: rejecting metrics that look good without being real).
