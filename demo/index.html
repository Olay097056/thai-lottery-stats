รัน backtest สูตรหวยกับผลรางวัลจริงในเบราว์เซอร์ แล้วดูว่าสูตรไหนชนะการสุ่มได้จริง — คำตอบที่ได้ส่วนใหญ่คือไม่ และนั่นคือประเด็นของโปรเจกต์นี้

ใช้ static/formula-engine.js ตัวจริงจาก repo นี้โดยตรง ไม่ได้เขียนใหม่ให้ demo ข้อมูลคือผลรางวัลจริงที่ scrape มา กำลังโหลด…
Edge = อัตราถูกจริง − อัตราที่ควรถูกด้วยการสุ่ม สำหรับการแทงประเภทนั้น — ถ้าไม่หักเส้นฐาน สูตรที่ทายเลข 2 ตัวจะดูเก่งกว่าสูตรที่ทายเลข 3 ตัวเสมอ ทั้งที่ยากคนละระดับ
สูตรที่เล็ง pool รางวัล (I / J2 / HM) ไม่อยู่ในหน้านี้ — ต้องประกอบ pool รางวัล 1–5 ต่องวด ซึ่งหนักเกินกว่าจะรันสดในเบราว์เซอร์
